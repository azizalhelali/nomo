🎮 كيف تبدأ
───────────────────────────────────────────────────────────────────────────────

1. افتح Terminal/PowerShell
2. انتقل للمشروع:
   cd web

3. ثبت المكتبات (إذا لم تكن مثبتة):
   npm install

4. شغّل الخادم:
   npm run dev

5. افتح المتصفح:
   http://localhost:3000

6. استخدم البيانات التجريبية:
   اسم المستخدم: demo
   كلمة المرور: demo123
